### 🎯 What I do
Final-year CSE student building **end-to-end AI systems** — RAG pipelines, LLM agents, and ML models shipped as production-ready, containerized APIs. Not just prototypes: things that deploy, scale, and get monitored.

### 🚀 Highlights
- **RAG & Agents** — LangChain/LangGraph pipelines with FAISS vector search, multi-agent workflows, tool-using chatbots with memory
- **Production ML** — FastAPI/Flask model-serving APIs, async inference, Pydantic-validated schemas
- **MLOps** — Docker + Kubernetes deployment, GitHub Actions CI/CD, DVC versioning, Prometheus/Grafana monitoring
- **Currently building** an LLM evaluation framework (RAGAS-based faithfulness & groundedness scoring) and a Gemini-powered multimodal chatbot
